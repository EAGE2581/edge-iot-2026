# RAG 报警自动分析 · 架构备忘

## 阶段划分
- 阶段 1（当前）：Web 聊天问答（用户主动问）
- 阶段 2（下一步）：报警自动分析（事件驱动）

## 阶段 2 架构
1. 报警处理器订阅 MQTT factory/+/+/+/alarms
2. 过滤：仅 critical 走 AI；warning/info 仅模板
3. 秒回：模板消息推钉钉（不调 LLM）
4. 异步：critical 报警入队
5. 后台 worker：取任务 → 调 RAG → 推补充消息
6. 限流：同时最多 3 个 LLM 调用

## 关键原则
- 报警响应不能等 LLM（先秒回）
- 报警不能无限调 LLM（限流 + 分级）
- RAG 是被调用的服务，不是订阅方
